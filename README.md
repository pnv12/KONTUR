# KONTUR 

Реалистичный стратегический симулятор войны с видом сверху (2D). Масштаб: от батальонов до армий. Играть можно за Украину или Россию.

> Статус: ранняя разработка (этап 0, технический каркас). Играбельной версии пока нет.

## Идея

Командуешь всеми силами сразу: от отдельных батальонов до фронтов. Ключевые принципы: реализм, удобное управление тысячами подразделений на телефоне, сложный и умный противник.

## Что планируется

Всё ниже в планах. Готово будет отмечено в разделе «Дорожная карта».

- Реальная структура войск: армии, корпуса, дивизии, бригады, батальоны
- Линия фронта, зоны контроля, окружения (котлы)
- Снабжение, заводы, производство, линии передач, мосты
- Мораль, усталость, местность с бонусами и штрафами
- ПВО, города, переговоры
- Сложный ИИ-противник и режим «ультра-хард»
- Красивая графика, рассчитанная на мобильные устройства

## Технологии

TypeScript, Vite, PixiJS, Vitest. Игра работает в браузере и рассчитана на смартфоны.

## Структура проекта

- src/sim: логика симуляции, без графики
- src/render: отрисовка
- src/ui: интерфейс
- src/data: данные (JSON) и схемы
- tests: тесты
- docs: документация (архитектура, правила разработки)

## Данные и нейтральность

Игра является симуляцией. Обе стороны играбельны по одинаковым правилам. Данные о составе войск берутся из открытых источников и являются приблизительными. Список источников ведётся в docs.
